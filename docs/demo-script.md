# ilchon 일촌 — 결선 시연 대본 (3~4분)

## 무대 준비 (발표 전에 끝내 두기)

노트북 한 대, 브라우저 하나에 탭 세 개를 열어요. 주소 뒤 `p=`가 사용자를 나누고, `demo=1`은 하루 한 번 제한을 20초로 줄여요.

| 탭 | 주소 | 역할 |
|---|---|---|
| A | https://ilchon.dongguri.org/?p=a&demo=1 | 나. 원화 10만 원어치 삽니다 +1% |
| B | https://ilchon.dongguri.org/?p=b&demo=1 | 루이스. 원화 9만 원어치 팝니다 +3% |
| C | https://ilchon.dongguri.org/?p=c&demo=1 | 마루. 원화 5만 원어치 삽니다 +1% |

1. 각 탭에서 **새로 시작하기** → **잠그지 않기** → **잠그지 않고 쓰기**. 백업 화면이 나오면 **나중에 할게요**.
2. 연결은 A–B, A–C 두 쌍만 해요. B와 C는 서로 모르는 사이예요.
3. 무대에서 시간이 없으면 연결까지 미리 해 두고, 조건 올리기부터 보여 줘요. 이미 쓰던 탭이면 올려 둔 조건이 없는지 확인해요.
4. 다른 창에 `pnpm exec tsx scripts/e2e.ts`의 ALL PASS 결과를 띄워 둬요 (대비책용).

### 붙여넣기로 연결하기 (한 쌍당 30초 안에)

QR 코드는 30초마다 바뀌어요. 복사하고 바로 붙여넣어요.

1. A 탭: 하단 **일촌** 탭 → **연결하기** → **코드 복사**
2. B 탭: **일촌** → **연결하기** → **상대 QR 찍기** → 아래 입력칸에 붙여넣기 → **이 코드로 연결**
3. B 탭: **내 QR** → **코드 복사**
4. A 탭: **상대 QR 찍기** → 붙여넣기 → **이 코드로 연결**
5. "연결됐어요"가 뜨면 이름을 적고 **저장하고 닫기** (A에서는 B를 "루이스", B에서는 A를 "나").
6. A와 C도 같은 순서로 연결해요 (C에서는 A를 "나", A에서는 C를 "마루").

## 대본

### 0:00 — 문제 (30초)

- 화면: A 탭의 빈 게시판.
- 말: "한국에서는 온라인으로 모르는 사람과 비트코인을 거래하다가 보이스피싱 돈이 섞여 들어와 통장이 묶이는 일이 많아요."
- 말: "그래서 거래소를 원하지 않는 사람도 거래소를 쓰고 개인정보를 내놓게 돼요. 거래소는 선택이어야지 강제가 되면 안 돼요."

### 0:30 — 연결 (40초, 미리 했으면 일촌 탭만 보여 주기)

- 동작: 위의 "붙여넣기로 연결하기" 1~5를 A–B에 대해 실행해요.
- 말 (연결하기 화면에서): "일촌은 직접 만나 30초짜리 일회용 QR을 서로 찍어야만 생겨요. 내 공개키만 알아서는 연결할 수 없어요."
- 말 (이름 입력에서): "이 이름은 제 기기에만 저장되고, 서버는 없어요."

### 1:10 — 조건 올리기 (50초)

1. B 탭: **게시판** → **조건 올리기** → **팝니다**, **원화 ₩**, 금액 `90000`, 수수료 `3` → **올리기**
   - 말: "루이스가 9만 원어치를 시세보다 3% 비싸게 판다고 올려요. 이 순간 이 조건은 아무에게도 보이지 않아요."
2. C 탭: **조건 올리기** → **삽니다**, **원화 ₩**, 금액 `50000`, 수수료 `1` → **올리기**
   - 말: "마루는 5만 원어치를 사려고 해요. 마루의 일촌은 저 하나뿐이에요."
3. A 탭: **조건 올리기** → **삽니다**, **원화 ₩**, 금액 `100000`, 수수료 `1` → **올리기**
   - 말: "저는 10만 원어치를 사려고 올려요. 지금 앱이 일촌 각자와 Marmot 방 안에서 몰래 맞춰봐요."

### 2:00 — 누가 무엇을 보나 (40초, 이 시연의 핵심 장면)

- A 탭: 맞은편 **팝니다** 칸에 루이스(9만 원, +3%)만 떠요. 마루는 없어요.
  - 말: "저에게는 파는 일촌 루이스만 보여요. 같은 방향인 마루는 보이지 않아요."
- C 탭: "아직 맞는 일촌이 없어요".
  - 말: "마루 화면에는 아무것도 없어요. 마루는 제 방향, 통화, 금액, 수수료를 알 수 없어요. 맞춰보기가 시작된 것만 알 수 있어요."
- B 탭: 맞은편 **삽니다** 칸에 나(10만 원, +1%).
  - 말: "맞춰보기는 ristretto255 위의 블라인딩으로 방향과 통화만 비교하고, 맞은 뒤에야 금액을 주고받아요."
- **A의 매칭은 조건을 올리고 20~30초 뒤에 떠요.** 떠보기를 막으려고 같은 일촌과는 한 창(시연 모드 20초)에 한 번만 맞춰보는데, 루이스가 먼저 조건을 올릴 때 이미 A와 한 번 맞춰봤기 때문이에요. 그동안 "일촌 n명 중 n명 확인했어요" 표시를 가리키며 이 이유를 설명하면 시간이 자연스럽게 채워져요.
  - 말: "같은 일촌과는 정해진 시간에 한 번만 맞춰봐요. 그래야 상대가 방향을 바꿔 가며 저를 떠볼 수 없어요."
  - 기다리기 싫으면 순서를 바꿔요: **A가 맨 먼저** 조건을 올리고, 20초 이상 지난 뒤 루이스와 마루가 올리면 바로 떠요.

### 2:40 — 방 열기와 거래 (50초)

1. A 탭: 게시판의 루이스 항목을 눌러요 (바로 방이 열려요. 일촌 탭에서 열 때는 **대화방 열기**)
   - 말: "누르면 둘만의 Marmot 방이 열려요. 중계 서버는 암호문만 봐요."
2. A 탭: 사는 쪽이 받는 쪽이므로, 라이트닝 지갑에서 만든 청구서를 **청구서 붙여넣기**(또는 입력칸에 붙여넣기) → **보내기**
   - 말: "비트코인을 받는 제가 라이트닝 청구서를 보내고, 원화는 계좌이체로 보내요."
3. B 탭: 같은 방에 청구서가 도착한 것을 보여 줘요.
4. A 탭: **거래 완료** → 거래한 금액 `90000` → **완료로 표시**
   - 말: "9만 원만큼 거래했고, 남은 1만 원 조건은 계속 열려 있어요."

### 3:30 — 마무리 (20초)

- 말: "Marmot은 중계 서버에게서 내용을 숨기고, 몰래 맞춰보기는 거래하지 않을 일촌에게서 거래 의사를 숨겨요."
- 말: "믿는 사람하고만 거래하고, 거래할 사람에게만 보여요. ilchon.dongguri.org에서 지금 휴대폰으로 써 보세요."

## 중계 서버가 느릴 때

- 연결이나 맞춰보기가 30초 넘게 멈추면 기다리지 말고 넘어가요.
- 빈 게시판을 보여 주며 설명해요: "조건을 올리기 전에는 아무것도 보이지 않아요. 맞지 않는 일촌도 똑같이 빈 화면을 봐요."
- 설정 화면에서 잠금 설계를 설명해요: "키는 패스키 PRF나 NIP-49 비밀번호로 잠그고, ncryptsec으로 백업해요. 서버가 없어서 연락처는 이 기기에만 있어요."
- 미리 띄워 둔 e2e 결과 창을 보여 줘요: "같은 시나리오를 실제 중계 서버 위에서 세 사용자로 돌린 기록이에요. A는 B만 보고, C의 상태와 저장소에는 A의 조건이 남지 않았어요."
- 말하지 않을 것: "익명이다", "추적할 수 없다", "과거 대화가 보장된다". "중계 서버는 내용과 보낸 사람 계정을 보지 못해요"까지만 말해요.

## 예상 질문과 답

| 질문 | 답 |
|---|---|
| 이게 통장 정지를 정말 막아 주나요? | 막아 준다고 말하지 않아요. 모르는 사람과 거래해야 할 이유를 없애요. 입금자 이름이 상대 본인인지는 직접 확인해야 해요. |
| 암호화 메신저에서 친구끼리 거래하는 것과 뭐가 다른가요? | 메신저에서는 올리면 방에 있는 전원이 봐요. 여기서는 거래가 성립하는 사람만 봐요. |
| 방향이 사기와 팔기 둘뿐인데 정말 숨겨지나요? | 혼자 계산해서는 알아낼 수 없어요. 알아내려면 맞춰보기에 참여해야 하고, 그러면 본인도 드러나요. 한 일촌과는 하루 한 번만 맞춰봐요. 며칠에 걸쳐 방향을 바꿔 가며 떠보는 건 막지 못한다고 한계에 적어 두었어요. |
| 왜 Marmot이어야 하나요? | 서버가 없어야 거래 의사와 인맥이 모이는 곳이 없어요. 전화번호 없는 신원과 메시지마다 바뀌는 일회용 키를 그대로 써요. |
| 시연이 실제 Marmot 위에서 도나요? | 네. 지금 보신 메시지는 실제 중계 서버(whitenoise relay)를 거친 Marmot 메시지예요. 대체 통신 경로는 두지 않았어요. |
| Vexl과 뭐가 다른가요? | Vexl처럼 인맥 안에서만 거래해요. 다른 점은 셋이에요. 전화번호가 필요 없고, 인맥이 회사 서버가 아니라 내 기기에만 있고, 제안이 인맥 전원이 아니라 거래가 성립하는 사람에게만 보여요. |
| Mostro, RoboSats, Hodl Hodl, Bisq와 뭐가 다른가요? | 그 서비스들은 낯선 사람끼리 공개 게시판에서 만나고 예치로 먹튀를 막아요. 여기는 게시판이 없고 아는 사람하고만 거래해요. 대신 예치와 분쟁 해결이 없어요. |
| 결과를 먼저 아는 쪽이 거짓말하면요? | 가능해요. 한계로 적어 두었어요. 응답 쪽은 해시 커밋만 보내서, 받은 값을 되돌려 보내 가짜로 맞은 척하는 것은 막았어요. |
| 키는 어디에 저장되나요? | 이 기기에만 있어요. 패스키 PRF로 만든 키나 NIP-49 비밀번호로 암호화하고, ncryptsec 백업으로 다른 기기에서 되살릴 수 있어요. 패스키 잠금은 실제 휴대폰에서 아직 검증하지 않았어요. |
| 중계 서버는 무엇을 보나요? | 암호문, 무작위 그룹 식별자, 시각, 접속 IP를 봐요. IP는 가리지 않아요. |
| 폰을 바꾸면요? | 키는 ncryptsec 백업으로 되살릴 수 있지만, 일촌과 방은 아직 백업되지 않아 다시 QR을 찍어야 해요. |
| 법적으로 괜찮나요? | 개인 간 가상자산 거래 도구의 법적 경계는 아직 확인하지 않았어요. 해커톤 시연판이고, 실제 거래는 본인 책임이라고 화면에 적어 두었어요. |
